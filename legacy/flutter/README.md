# Scaffold Flutter cũ — chỉ để tham khảo

Mobile đang phát triển đã chuyển sang **React Native + Expo + TypeScript** tại [../../mobile](../../mobile).

Thư mục này giữ nguyên code Dart/pubspec cũ để đối chiếu UI. Luồng anti-spoofing, persona bắt buộc, thưởng và mock trong code này không phải yêu cầu MVP hiện hành. Không chạy Flutter như frontend chính và không sửa legacy để phát triển tính năng mới.

Xem [đặc tả hiện hành](../../docs/PROJECT_SPECIFICATION.md) và [hướng dẫn mobile](../../mobile/README.md).
